Professional web developers live in a handful of free services. Make these accounts now so nothing stops you later. Use the same email and, where you can, sign in with GitHub so everything connects.

Read
----

Your GitHub profile is your portfolio. Employers read it. Pick a username you'd put on a resume, add a photo or avatar, and fill in your name.

Stuck? Ask your study buddy
---------------------------

Use AI to explain, not to do the work for you. Paste your own code or error with the prompt, read the answer, then close the chat and type the fix yourself. If you can't explain the fix out loud, you don't own it yet.
