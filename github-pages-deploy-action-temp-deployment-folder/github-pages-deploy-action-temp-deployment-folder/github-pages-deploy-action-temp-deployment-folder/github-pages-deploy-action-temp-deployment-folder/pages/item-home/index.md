HAX Lab is where students and junior developers learn web development by shipping real work in HAX, the open source web publishing platform built at Penn State. Interns spend a term in the College of Arts and Architecture, and each one owns one real project: a theme, the command line, the design system, the dashboard. What they build ships to everyone who uses HAX.

HAX Lab in the HAX network
--------------------------

The lab is one stop in a network of HAX sites. You'll use all of them in onboarding.

*   [HAXTheWeb](https://haxtheweb.org): what HAX is for and every way to get it.
*   [PRAW (hax.cloud)](https://hax.cloud/hax-lab): the stories behind the lab and the people in it.
*   [Build now](https://browser.hax.cloud): make a HAX site in your browser tab, nothing to install.
*   [Learn](https://learn.hax.cloud): tutorials for using HAX one flow at a time.
*   [Web components](https://webcomponents.hax.cloud): every HAX element with a live demo, including ones lab students built.
*   [The issue queue](https://github.com/haxtheweb/issues/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22HAX%20Lab%20%E2%99%8E%2B%F0%9F%83%8F%2B%F0%9F%94%A5%20%3E%20%F0%9F%92%B8%22): work tagged for the lab.
