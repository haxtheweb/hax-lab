Move your CodePen card into my-card.js. The parts that changed from card to card become properties. The description becomes a slot so it can hold real HTML. Your colors and spacing become DDD tokens. Then you let tools check your work before a human does.

  • Read and watch: about 20 minutes
  • Do: about 1 to 2 hours
  • You make: a my-card element used five different ways in index.html
  • You need: your Project 1 pen and the my-card project
  • Support level: medium

Read and watch

  • Lit cheat sheet: properties, reflect, events and slots on one page (use JS).
  • Code crit of a past class's cards: what went well and what didn't.

Do

Paste your card's HTML into render() and its CSS into static get styles(). Leave the imports, haxProperties and the translation code that the generator wrote alone; you'll use them later.

Every value from your properties list becomes a property: declare it in static get properties(), give it a default in the constructor, use it in render(). Aim for at least three: title, image and one more.

Put a <slot></slot> where the description goes. Add a fancy Boolean with reflect: true, then style it with :host([fancy]).

In index.html, make five different cards with attributes alone. No JavaScript in index.html.

Run npm run dddaudit (or hax audit) in the project folder and fix what makes sense: it points at values that should be DDD tokens. Then open your demo, right click, Inspect, and run the Lighthouse tab with Accessibility ticked. Fix every red item. Try the WAVE extension too.

Before you move on

  • All human-readable text comes from a property or a slot, never typed into render().
  • Selectors use classes. No id lookups.
  • Comment each method in plain words. You should be able to explain every line.

Stuck? Ask your study buddy

Use AI to explain, not to do the work for you. Paste your own code or error with the prompt, read the answer, then close the chat and type the fix yourself. If you can't explain the fix out loud, you don't own it yet.
