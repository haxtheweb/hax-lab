Support fades as you go
-----------------------

The early pages hold your hand. Later pages give you the goal and fewer steps, and the last chapter gives you a real problem with no steps at all. That's by design. It's the same path every HAX contributor has taken: watch someone do it, do it with help, do it alone, then teach the next person. HAX calls this loop SIIP, and it is how a project with one full time developer keeps shipping: students learn real skills, the best work comes back into the project, and the next group starts further ahead.

About AI
--------

AI is your study buddy, not your ghostwriter. Some pages tell you to use it (filling in data, wiring up a fetch). One page tells you not to (the button controls), because that's where the skill you need to keep is. Claude works well in a browser tab at [claude.ai](https://claude.ai). If you're on a paid plan, the [Claude in Chrome](https://claude.com/chrome) extension can read the page you're on, which helps when a tutorial and your code are side by side.
