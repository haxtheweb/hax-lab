HAX Lab onboarding is for students and junior developers. It takes you from knowing nothing about how websites are built to opening your first contribution to HAX, an open source web publishing project used across Penn State and beyond. You don't need any experience. You need a computer you can install software on, about two hours per page, and the willingness to break things on purpose.

What you'll be able to do at the end
------------------------------------

*   Explain what happens between typing an address and seeing a page.
*   Build a card in HTML and CSS, then turn it into a reusable web component.
*   Style it with a design system instead of one-off colors.
*   Ship it: push code to GitHub and have Vercel publish it every time you push.
*   Feed it JSON data, render a list of cards, and control them with buttons you wire yourself.
*   Make a HAX site, edit it on your own computer, publish it, and pick an issue to work on.

How it's built
--------------

It's the opening weeks of Penn State's web development course, the one HAX grew out of, rebuilt so you can do it on your own schedule. It doesn't live in an LMS. You learn the web by using the web: every page sends you out to real tools, real code and real projects, then brings you back to check yourself.

This site is itself a HAX site, and its source is public at [github.com/haxtheweb/hax-lab](https://github.com/haxtheweb/hax-lab). In chapter 6 you'll fork it, change it with HAX blocks, publish your copy, and send a fix back. The course is part of the assignment.
