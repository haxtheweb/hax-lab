Every bug, idea and task for every HAX repository lives in one place: the [unified issue queue](https://github.com/haxtheweb/issues). Contributing starts with reading it, not with writing code. A good first issue is one you understand, can reproduce, and can finish.

<stop-note status="info" title="At a glance"><div slot="message"><ul><li><strong>Read and watch:</strong> about 20 minutes</li><li><strong>Do:</strong> about 1 hour</li><li><strong>You make:</strong> a shortlist of three issues and one comment</li><li><strong>You need:</strong> your GitHub account</li><li><strong>Support level:</strong> light</li></ul></div></stop-note>

Read
----

*   [Open issues labeled Good first issue](https://github.com/haxtheweb/issues/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22Good%20first%20issue%22).
*   [Help Wanted](https://github.com/haxtheweb/issues/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22Help%20Wanted%22) and [Design Challenge](https://github.com/haxtheweb/issues/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22Design%20Challenge%22) for when you want more.
*   [Contributing to a project (GitHub)](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project): forks and pull requests.

Do
--

<ddd-steps-list><ddd-steps-list-item step="1" title="Read ten issues"><p>Don't pick yet. For each one, can you say in one sentence what's wrong or wanted? Which repository and element does it touch?</p></ddd-steps-list-item><ddd-steps-list-item step="2" title="Shortlist three"><p>Pick three you could explain to a friend. Prefer ones with screenshots, steps to reproduce, or a plan already written in the comments (look for the Plan Created label).</p></ddd-steps-list-item><ddd-steps-list-item step="3" title="Reproduce one"><p>Make the bug happen yourself, or find the place in the code where the feature would go. If you can't reproduce it, that's useful information too.</p></ddd-steps-list-item><ddd-steps-list-item step="4" title="Say hello"><p>Comment on that issue: what you found, what you think the fix is, and that you'd like to try. Be specific and brief. Someone will answer.</p></ddd-steps-list-item></ddd-steps-list>

Stuck? Ask your study buddy
---------------------------

Use AI to explain, not to do the work for you. Paste your own code or error with the prompt, read the answer, then close the chat and type the fix yourself. If you can't explain the fix out loud, you don't own it yet.
