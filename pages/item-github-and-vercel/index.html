Your card only exists on your computer. In this step it goes to GitHub, where your history and your portfolio live, and Vercel watches that repository and publishes a fresh build every time you push. That loop is called CI/CD: continuous integration and continuous delivery. It's how almost every professional team ships.

  • Read and watch: about 20 minutes
  • Do: about 1 hour
  • You make: a my-card repository on GitHub and a live my-card address on vercel.app
  • You need: GitHub Desktop or git, and your Vercel account
  • Support level: full, two ways

Do: get it on GitHub

Open GitHub Desktop. Windows: File, Add local repository. macOS: File, Add Local Repository. Pick your my-card folder. hax already made it a git repository.

The left side lists every changed file. Type a summary like Port my card into a web component and press Commit to main.

Press Publish repository. Untick Keep this code private so others can see and learn from it. Open it on github.com to check.

Change code, come back to GitHub Desktop, write a summary, Commit, then Push origin.

On github.com press New repository, name it my-card, and don't add a README (your folder already has one).

git add ., git commit -m "what changed", git push.

Do: connect Vercel

On vercel.com/new, pick your my-card repository and press Import.

Build command npm run build, output directory public. Vercel usually guesses; fix them if it doesn't. Press Deploy.

Read the build log as it runs. When it's done you get a something.vercel.app address. Open it on your phone.

Change your card, commit, push. Watch Vercel build again on its own. Your card now updates itself.
